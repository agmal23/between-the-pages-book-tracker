# Between the Pages — Book Tracker

A personal reading tracker designed to help readers organize their books, monitor their reading progress, and build a consistent reading habit.

## Features

- **Add books:** Save a book's title, author, and reading status.
- **Reading statuses:** Organize books into To Read, Currently Reading, and Finished.
- **Search:** Find books by title or author, regardless of capitalization.
- **Filter:** View books by reading status.
- **Reading statistics:** Track total books and counts for each reading status.
- **Persistent storage:** Keep your collection saved in the browser using localStorage.
- **Delete books:** Remove books from your collection with a confirmation step.
- **Responsive design:** Use the application on desktop and mobile screens.
- **Form validation:** Prevent submission when the title or author is missing.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No framework, package installation, or backend server is required for the basic application.

## How to Use

1. Select **Add a book**.
2. Enter the book title and author's name.
3. Choose the reading status.
4. Search or filter your collection as needed.
5. Update a book's status or remove a book when necessary.

Your collection is stored locally in the browser. It is not automatically synchronized across devices or browsers.

## Project Structure

- `index.html` — application structure
- `style.css` — styling and responsive layouts
- `script.js` — book management, search, filtering, statistics, and storage
